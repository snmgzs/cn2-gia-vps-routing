## 先把“直连”和“CN2 GIA”这两个词拆开

普通163线路（AS4134）的问题不在带宽标称，而在晚高峰的共享拥塞：延迟冲到300ms以上，丢包率可能超过10%，网页图片加载到一半卡住，SSH敲一个命令等三秒。CN2 GT好一些，但回程不一定走优化路由，高峰期照样抖。

所以判断一台机器是不是“真直连”，看两件事就够了：

- **去程**：从国内出去时走的是不是59.43节点，还是被丢进公共互联网。
- **回程**：数据从美国回来时走哪条线。这一头比去程更关键，因为你刷网页、拉数据、看后台，绝大部分流量是回程方向。一台洛杉矶机器如果晚高峰回程走163，白天测速再漂亮，晚上也是另一台机器。

## FAQ

**CN2 GIA 和 CN2 GT 到底差在哪？**
GT是入门版本，高峰期会走普通节点，容易绕路；GIA全程走专用高速通道，去程回程都优化。实际数字上，普通163线路晚高峰延迟300ms以上、丢包可能超过10%，GIA能稳在150-160ms、丢包接近零。这个差距不是测速软件上的小数点，是页面能不能一次加载完的区别。

**回程和去程哪个更重要？**
回程。你访问网站、拉取数据、看后台，绝大部分流量是服务器发回国内的，回程走163的话，去程优化得再好也救不回来。选机器时优先确认回程线路，再看去程。

**超流量会不会直接断网？**
LisaHost的套餐页面只标了双向流量额度，超量后的处理方式没有明示，下单前建议工单确认。作为参考，DMIT Pro系列的处理是不断网、降速到4-8Mbps继续跑，静态站点基本不受影响。

**IP被墙了怎么办？**

LisaHost CERA当前展示的以月付和季付为主，没有年付报价；AkkoCloud的年付便宜但明确不退款；DMIT买价即续费价，没有首年特价次年涨价的套路。第一次接触一个品牌，优先选月付或短期方案，用一两个月再决定要不要长期锁。LisaHost给的48小时退款窗口，就是为这个场景准备的。
